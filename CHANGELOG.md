# Changelog

## v1.0.0

- Android reading for EPUB and fixed-layout EPUB, PDF, FB2, TXT and CBZ.
- EPUB table of contents, internal links, reading position restoration, bookmarks and highlights.
- Fixed a WebView constructor required by positioned fixed-layout EPUB text.
- CBR/RAR extraction is unavailable. Previously imported CBR files can still be exported.
- Fixed-layout EPUBs with unembedded fonts use Android fallback fonts.
- Google Books discovery requires a key supplied at build time.
