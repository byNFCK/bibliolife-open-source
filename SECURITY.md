# Security

BiblioLife is under development; no supported release versions or dedicated security contact have been established. Please do not publish vulnerability details, credentials, personal books or user data in public issues. If the eventual repository enables GitHub private vulnerability reporting, use that private channel. Until a private reporting channel is established, avoid posting sensitive details publicly.

Android release builds are unsigned unless a private release key is configured. They must not be distributed until a production signing identity and certificate continuity are verified; see [build and release](docs/development/build-and-release.md).
